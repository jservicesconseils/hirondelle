Hirondelle est une application développée par J Services Conseils Inc. destinée à la gestion des membres, des événements et des communications des communautés, associations et organisations.

Données collectées

L'application peut collecter les informations suivantes :

  • Nom et prénom.
  • Adresse courriel.
  • Numéro de téléphone.
  • Adresse (si renseignée par l'utilisateur).
  • Photo de profil (si ajoutée volontairement).

Utilisation des données

Ces données sont utilisées uniquement pour :

  • créer et gérer le compte utilisateur;
  • permettre les communications entre les membres;
  • gérer les événements et les inscriptions;
  • assurer le bon fonctionnement de l'application.

Partage des données

Les données personnelles ne sont ni vendues ni partagées avec des annonceurs. Elles sont uniquement utilisées pour fournir les services de l'application.

Sécurité

Les communications entre l'application et les serveurs utilisent un chiffrement sécurisé (HTTPS/TLS).

Conservation des données

Les données sont conservées tant que le compte utilisateur est actif ou jusqu'à la demande de suppression.

Vos droits

Vous pouvez demander la modification ou la suppression de vos données personnelles en nous contactant.
