Pourquoi Hirondelle

Une plateforme simple pour vos communautés.

Groupes, membres, événements publics ou réservés : tout se gère au même endroit, du bureau comme du téléphone.

Des groupes cloisonnés

Chaque groupe voit ses membres et ses événements. Les événements privés restent invisibles pour les autres groupes.

Invitation par texto

À sa création, chaque membre reçoit un message avec le nom de son groupe et le lien vers l'application mobile.

Billets et code QR

La réservation génère un billet avec code QR, consultable hors ligne dans l'onglet Billets de l'application.

Accès par rôle

Super administrateur, administrateur de groupe ou membre : les droits sont vérifiés côté serveur, pas seulement à l'écran.
