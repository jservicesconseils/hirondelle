Besoin d'aide ? Seules les colonnes Prénom et Nom sont obligatoires ; une colonne Téléphone est recommandée pour les boutons Appeler/WhatsApp. Une colonne Groupe (Pasteur, Diacre, Administrateur… tout regroupement propre à votre communauté) devient les onglets de l'annuaire mobile. Toutes les autres colonnes de votre fichier — Genre, Profession, Email, Ville, ou n'importe quel champ qui vous est propre — sont importées telles quelles, sous leur en-tête exact.
